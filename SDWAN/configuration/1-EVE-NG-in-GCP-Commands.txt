Step-1: Use below keyword at the end of command generated by google cloud to enable nested virtualization,

"--enable-nested-virtualization"



Step-2: To download and install EVE-NG on Ubuntu machine in GCP, follow my video and use below commands,
sudo -i
wget -O - http://www.eve-ng.net/focal/install-eve.sh | bash -i
apt update
apt upgrade
reboot

Step-3: once you get the ui
you need to press ctrl + C
just type: sudo -i

Configure all parameters as shown in videos.

Step-2 Launch Installation:
sudo -i
wget -O - https://www.eve-ng.net/focal/install-eve.sh | bash -i
