en

host R1
int g0/0
ip add 11.1.1.1 255.255.255.0
no shut
int l1
ip add 10.1.1.1 255.255.255.0


ip route 0.0.0.0 0.0.0.0 11.1.1.10


crypto isakmp policy 1
hash md5
authentication pre-share
group 2
encryption des
lifetime 3600
!
crypto isakmp policy 2
hash sha
authentication pre-share
group 2
encryption des
lifetime 3600
ex
!
crypto isakmp policy 3
hash md5
authentication pre-share
group 2
encryption 3des
lifetime 3600
ex
!
crypto isakmp policy 4
hash sha
authentication pre-share
group 2
encryption 3des
lifetime 3600
ex

!!!!!  Authentication !!!!!!!!
crypto isakmp key cisco address 15.1.1.1

!!!!!  Authentication for phase 2 !!!!!!!!
crypto ipsec transform-set TSET esp-3des esp-md5-hmac

!!!! policy based uses access-list  !!!!!!!
access-list 101 permit 10.1.1.0 0.0.0.255 10.2.2.0 0.0.0.255 

!!!!! Whatever we used in phase 1 & 2 !!!!!!
crypto map CMAP 10 ipsec-isakmp
set peer 15.1.1.1

!!!!! access-list apply
match address 101
set transform-set TSET
exit

!!!!! call the crypto map where you wanna apply this rule
